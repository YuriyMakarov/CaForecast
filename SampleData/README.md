# Примеры CSV для импорта

В папке лежат готовые файлы для загрузки через WPF-приложение.

## 1. `revenue_by_direction.csv`

Формат с явным указанием направления:

```csv
direction;metric_date;metric_value
Разработка на Python;2025-01-01;420000
```

Когда использовать:
- если в одном файле хранится несколько направлений обучения;
- если направление нужно определять автоматически из CSV.

## 2. `contracts_python.csv`

Формат без столбца `direction`:

```csv
metric_date;metric_value
2025-01-01;24
```

Когда использовать:
- если файл относится только к одному направлению;
- если имя направления вводится в поле `Имя направления при импорте` в интерфейсе.

Рекомендуемое имя направления для этого файла:
- `Договоры | Разработка на Python`

## 3. `leads_design.csv`

Тот же формат, но с разделителем `,`, чтобы проверить автодетект разделителя:

```csv
metric_date,metric_value
2025-01-01,118
```

Рекомендуемое имя направления для этого файла:
- `Лидогенерация | Графический дизайн`

## Требования к данным

- `metric_date` — дата в формате `yyyy-MM-dd` или `dd.MM.yyyy`
- `metric_value` — положительное числовое значение
- пропуски и некорректные строки будут пропущены при импорте
- дубли по одной дате для одного направления при импорте схлопываются
